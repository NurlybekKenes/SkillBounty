Changes made during review

Severity Finding Change Remaining verification
High A submitted bounty had no worker-side timeout path if the employer never approved it. Funds could remain locked indefinitely. Added a seven-day review deadline and claim_after_review_timeout, which permits only the recorded worker to release the escrow after the review period. Covered by the seven passing LiteSVM tests; Devnet behavior remains unverified.
Medium A public PDA can receive unsolicited SOL; transferring only the original bounty amount could leave dust stranded. Approval, timeout claim, and expiry refund now release the full PDA balance to the designated worker or employer, after checking it covers the recorded amount. Local lifecycle tests pass; confirm donation edge cases during an independent review before real user funds.
Medium An off-curve address cannot sign as a worker and should not be assignable. Assignment now rejects off-curve worker addresses. Added a corresponding LiteSVM case. Covered by local program compilation and LiteSVM tests.
High readiness The client is integrated, but the program is not deployed on Devnet. The live chain flow cannot yet be demonstrated. The UI checks for an executable Devnet program and keeps actions disabled until deployment. It requests wallet confirmation before any transaction. Deploy to Devnet only with explicit authorization, then test all lifecycle paths using test wallets and verify explorer records.
