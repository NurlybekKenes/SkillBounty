SkillBounty

Small projects. Verifiable proof of work.

SkillBounty helps early-career analysts and developers find small, paid projects that match skills they can demonstrate. Teams post a scoped task, review explainable candidate recommendations, and choose a worker themselves. The prototype includes sample analytics bounties, fictional candidate profiles, a deterministic skill-overlap score, and a local-only project draft flow.

For students and junior specialists, the first real project is often the hardest to get. Coursework does not always show how someone works with a real brief, and a CV alone gives a small team little evidence for a short engagement. Small companies, in turn, may need a focused data or product task completed without running a full hiring process.

SkillBounty narrows that gap to one bounded project: a team describes a result and required skills; candidates can be ranked by transparent evidence; the team makes the final selection and evaluates the work. The current matching endpoint is a rule-based prototype over sample data. It does not use a hosted LLM, make hiring decisions, or persist submitted drafts.

Solana is intended to provide a shared payment and receipt layer for cross-team work. The Anchor source models employer-funded SOL escrow, worker assignment, submission hashes, employer approval, payout, and expiry refunds. The code keeps briefs and deliverables off-chain. At this the Anchor program builds locally and seven LiteSVM tests pass. A typed Codama client is integrated into the wallet UI. The program has not been independently audited or deployed; no Devnet transaction is available to demonstrate.

The web prototype uses Next.js, TypeScript, Solana Kit wallet discovery, and an Anchor program workspace. Local validation covers the Windows production build, TypeScript, scoped lint, Anchor compilation, and seven LiteSVM tests. This workspace still needs a clean Linux dependency install to verify an Ubuntu web build. The next technical milestone is an explicitly authorized Devnet deployment followed by wallet-based lifecycle verification.
